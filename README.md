# Heba Ahmed Portfolio

A static bilingual portfolio for Heba Ahmed. No build step or server required.

## Files

- index.html: page shell and metadata
- style.css: visual design and responsive layouts
- app.js: English and Arabic content, project filters and project pages
- assets/: real project images, portrait and CV downloads

## GitHub Pages

Create a repository called `portfolio` in `hebaahmd-ux`. Upload the CONTENTS of this folder, including `index.html`, `style.css`, `app.js`, `.nojekyll` and the full `assets` directory, to the repository root.

In the repository, open Settings > Pages and select deployment from the main branch, root directory. The intended address is `https://hebaahmd-ux.github.io/portfolio/` after GitHub completes deployment.

Use a local HTTP server for development rather than opening index.html directly, because project presentations load assets/manifest.json with fetch.

## Updating

Edit bilingual copy and project descriptions in app.js. Add presentation images under assets/ and register them in assets/manifest.json. Replace assets/Heba_Ahmed_CV.pdf and assets/Heba_Ahmed_CV.docx to update CV downloads. The selected language is remembered in the visitor's browser.
